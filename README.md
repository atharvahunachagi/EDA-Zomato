# EDA on Zomato Dataset

## Project Overview
This project performs Exploratory Data Analysis (EDA) on the Zomato dataset using Python.

## Files
- EDA.ipynb : Jupyter Notebook containing the analysis
- zomato.csv : Main dataset
- Country-Code.xlsx : Country code mapping

## Libraries Used
- pandas
- numpy
- matplotlib
- seaborn

## Objectives
- Data Cleaning
- Handling Missing Values
- Data Visualization
- Finding Business Insights
